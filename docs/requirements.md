# Project Requirements

## Functional Requirements

1. Create and manage projects
2. Upload CSV datasets
3. Select criteria from dataset columns
4. Add decision makers (experts)
5. AHP pairwise comparisons for each expert
6. WAM aggregation of expert weights
7. SAW analysis and ranking
8. Export results to CSV

## Non-Functional Requirements

- Performance: < 2s page load
- Security: Supabase authentication
- Compatibility: Chrome, Firefox, Edge
